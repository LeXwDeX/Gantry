服务端 本机

模型

三类模型分工，保存在服务端，对所有项目生效；项目可在「项目设置」里覆盖。提供方凭据只存在服务端，桌面端不保存。
打杂 打杂模型
摘要 PR 事件、分类 CI 日志、生成提交说明与状态清单。量大、要便宜。
大脑 大脑模型
规划拆图、需求准入问答、reasoner 预演、arbiter 裁决。量少、要准。
干活 干活模型
实现、修复、各 review 视角。主力产量，按档位调推理深度。

档位如何调用三类模型

档位 大脑 干活 打杂
None不调用单轮回答—
Low不调用单节点实现提交说明
Medium规划plan / build / verify状态清单
High规划、准入实现 + 多角色 review事件摘要
Max规划、reasoner、arbiter实现 + 对抗 review事件摘要
Ultimate拆 Milestone、每个 PR 裁决多 PR 并行，每个按 Max事件摘要
