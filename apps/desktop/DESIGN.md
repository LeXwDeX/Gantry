# 桌面前端基线

## 验收依据

视觉与交互以 `../../docs/prototype.md`、`../../prototype/Main.dc.html`、`../../prototype/Settings.dc.html` 为准，不重新设计。协议与安全规则以 `../../docs/interfaces/api.md`、`../../docs/data-model.md`、`../../docs/interfaces/config.md`、两份桌面模块规格为准。原型里的模拟签名、模拟 GitHub 审批和假保存成功不进入实现。

用户已确认 React + TypeScript + Vite。只修改 `apps/desktop/**`，不修改后端或共享契约，不自动提交。

## 视觉约束

- 工作区占满窗口。顶栏 44px；左栏约 240px；中栏弹性；检视器约 300px；底部状态栏。各栏内部滚动，输入区保持可见。
- 900px 及以下三栏依次堆叠，整页滚动，不产生页面横向溢出；表格和关系地图可在各自容器内滚动。
- 底色 `#0E1014`，面板 `#111418`，气泡与卡片 `#151920`，深层底色 `#0F1216`，分隔线 `#22272E`，控件边框 `#2A3038`。
- 正文 `#E6E8EB`，次要文字 `#A9B1BA`，弱文字 `#8B949E`。运行蓝 `#58A6FF`，需要你黄 `#E3B341`，通过绿 `#3FB950`，失败及缺规格橙 `#F0883E`，空闲灰 `#6E7681`。
- Inter 配中文系统回退，正文 12–13px；编号、分支、时间、摘要用 JetBrains Mono。字体随包，无远程字体请求。
- 大脑紫 `#A371F7`，干活青 `#39C5CF`，打杂灰 `#8B949E`。气泡为 2px 完整边框并显示种类文字，无头像。未知种类为中性灰。
- 设置为全屏浮层，不卸载工作区。左导航约 200px，内容最大宽 980px，三张模型卡间距 12px。审批为右侧 540px 抽屉。

## 本次交付范围

交付可交互的工作区、项目切换、对话、上下文、上限选择器、检视器、关系地图、工作树、收件箱、审批展示、设置模型页、项目覆盖基础页、设备页和配对界面。数据经规格中的 `IpcAdapter`，不得从组件直接读 fixture 或联网。

开发场景替身只回放契约形状的示例快照和可控交互结果，不实现引擎、策略、证书或签名。示例模式始终可见；签名与受保护写入不返回假成功。生产包不静默回退到示例模式。

共享机器可读 schema 尚未交付。前端类型暂按已有文字契约转写并注明来源，不增路由或协议字段，不冒充自动生成类型。模型枚举和推理深度仍从 `settings.catalog` 读取。通用 schema 表单与正式 Mock API 联调在共享 schema 到位后完成。

## 验收

类型检查、构建、纯逻辑与交互测试通过；1440×900、390px 窄屏实际截图与原型源码中的几何、配色、字体、内容层级核对；独立评审通过。真实后端、Tauri 原生安全边界、Touch ID / Windows Hello、系统通知与安装包不由浏览器替身测试宣称通过。
